# WeatherAppProfessional 
A professional desktop weather application written in modern C++.

## Planned Features
- Current weather
- 7-Day forcast
- Multiple weather providers
- Air quality
- UV index
- Favorite cities
- Modern Qt GUI
- Dark mode
- Offline Cache
- Charts and analytics

## Technologies
- C++ 17
- CMake
- Ot 6 (planned)
- libcurl
- nolhmann/json 
- Git
- GitHub
